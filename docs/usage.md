# 使用 Kairos

## 安装到手机

使用 HTTPS 打开自己的 Kairos 实例并登录，在账号菜单或「设置 → 安装到手机」查看安装入口。
支持直接安装的浏览器会显示「安装 Kairos」按钮；确认后可从主屏幕图标打开独立的应用窗口，进入首页记录。

- **iPhone / iPad**：用 Safari 打开网站，在「分享」中选择「添加到主屏幕」。如果出现「作为 Web App 打开」，请开启后添加。
- **Android**：用 Chrome 打开网站，点击应用内安装按钮，或在浏览器菜单中选择「安装应用 / 添加到主屏幕」。
- 微信等应用内浏览器可能不提供安装，请先转到 Safari 或 Chrome。电脑端也可使用支持安装的浏览器地址栏或菜单。

手机访问需要 HTTPS；开发时仅本机的 localhost / 回环地址可例外使用 HTTP，局域网 IP 的 HTTP 地址不满足条件。
安装后先从主屏幕联网打开并登录一次，让应用准备离线记录。浏览器与已安装应用可能使用不同的存储空间，
切换前先同步已有草稿。离线保存仍只在当前设备，恢复联网登录后继续同步；清除应用数据或卸载可能丢失未同步草稿。

安装选项由浏览器决定，普通标签页可能无法识别此前的安装；从应用图标进入时会显示已安装状态。
安装不会自动替你登录，也不等于记录已备份。安装指引参考 [Apple 使用说明](https://support.apple.com/guide/iphone/iphea86e5236/ios)
和 [MDN PWA 安装说明](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

## 记录与编辑

打开首页，留下文字、照片或声音后保存。标题、标签、位置和分区都可以不填。
编辑器直接渲染 Markdown；「Markdown 源码」和「切换可视化编辑」使用同一份正文，
也可用格式按钮插入标题、列表、链接、引用和代码。旧内容不会因切换模式重新序列化。
「聚焦」就在编辑器上方；退出聚焦会保留正文、光标、附件和选定的元数据。
桌面可使用 Cmd/Ctrl+Enter 保存；普通 Enter 换行。

复制图片后直接粘贴，图片会插入当时的光标位置；图文混合粘贴保留可识别的基本格式。
Shift+Cmd/Ctrl+V 可粘贴纯文本。上传失败时保留本机文件并显示重试，待处理图片完成后才能完整保存。
「草稿已保存在此设备」与服务器确认是不同状态；浏览器数据被清除或设备丢失时，尚未同步的草稿无法从服务器备份找回。

离线使用需要这个浏览器此前成功打开并登录过应用。恢复联网后会继续待处理上传；
保存冲突保留本机草稿，不能把旧服务器内容当成本次修改已成功。录音还取决于 HTTPS、设备权限和浏览器支持。

## 搜索、标签与置顶

「查找记录」直接输入关键词，可组合日期、标签、分区和图片/音频/附件条件。
多个关键词共同匹配；可使用引号保留一个词组。普通搜索把引号、百分号等作为内容处理，
需要表达式时再展开高级筛选。没有结果与请求失败分别显示，失败可重试。

「未添加标签」可以一键找到尚未整理的记录。`#人生修行/觉察` 会显示为可折叠标签树；
选择父标签包含其子标签，`人生修行者` 不会误算在 `人生修行` 下。展开状态在当前浏览器保留。
筛选中的「仅本级」只匹配正文实际写出的完整标签，不把只有子标签的记录算入父标签。
标签计数和日历反映当前条件；切换到全部自己的记录可同时检索正常与归档内容，回收站仍排除。

记录菜单中的「置顶」会在当前筛选范围内优先展示，不改变原日期，也不重复记录。
归档和回收站不会把记录带回首页；恢复后仍遵循记录本身的置顶状态及当前筛选。

## 位置、日历与关联

「添加位置」可搜索地点、选择近期地点或保存常用地点，也可主动请求设备定位。
定位失败、低精度和地址解析失败会显示说明；确认前可以手动调整。默认地图中心不是已选地点，
手动选择后迟到的定位结果不会覆盖选择。常用地点改名不会改写历史记录的位置。
地点搜索和地址解析需要联网；设备定位仍受浏览器权限与所在环境影响。

活动日历按数量着色，点击日期回到当前筛选下的当天记录，日期按 Kairos 时区计算。
地图呈现已经保存位置的记录。

「关联记录」可搜索、预览并选择已有记录，关闭后继续原处写作；保存后在两端看到引用关系。
自己、已选记录、回收站和无权限记录不能再次关联。若目标在保存前已失效，正文仍可保存，
界面会说明被略去的关联；打开时也会重新检查可读权限。

## 随便看看与 Agent

每日回顾和随机漫步由你主动进入。可以打开原记录，也可以随时返回，不产生阅读任务。
AI 洞察需要配置服务、手选来源并点击开始。发送范围在使用前说明；原记录不会被自动改写。

「设置 → Agent / MCP」可创建独立、限期、可撤销的只读凭据。
Agent 可以按今天、指定日期或时间段查询自己的记录，读取完整正文及来源，不能写回或修改设置。
涉及多页结果时必须继续读取到结束；具体配置和权限范围见 [MCP 使用说明](operations/agent-access.md)。

## 分享与分区外发

先选定记录和范围，查看访客预览后创建链接。固定分享是快照；动态分享会按明确授权的范围变化。
分享可以设提取码、期限、暂停和轮换。链接分享不能代替指定身份访问控制。

分区帮助本人整理内容。只有明确配置并启用的分区才自动向接收服务投递；保存时显示外发目标。
正文和分区一次提交，外发依据成功保存后的最终授权。投递回执与外部平台真正发布成功是不同结果。
真实社媒平台接入仍暂缓，不代表已支持这些平台。

## 附件、最近删除与备份

记录可以编辑、查看保留版本，也可以移入最近删除后恢复。彻底删除需要明确确认。
附件库区分正常与回收站内容；随记录回收的附件不再计入正常列表，恢复时按仍存在的引用重新归类。
仍被其他可读记录或历史版本引用的原件不会被当作无用文件清理。清理遵守保留期和引用检查。
恢复内容保持私密，撤回旧分享并暂停该记录的同步。普通编辑仍保持暂停；需要再次同步时，
在编辑器重新选择分区后保存。恢复前已打开的分享预览需要重新生成，才能再次授权分享。

「数据与备份」中的个人 ZIP 档案可带走内容；完整实例恢复需要数据库和媒体备份。
安装宿主备份代理后，管理员可配置 S3 兼容目的地，先实际读写检测并完成试备份，再启用定时任务。
检测失败不会替换原有效配置。独立状态页显示最近保护时间、任务、错误、检查、隔离恢复和监控状态。
隔离应用验收成功后，状态页记录实际测试的版本、提交和时间；文件校验成功与应用验收成功分别展示。

内置实例备份目前保护 SQLite、本地附件和受管理 S3 原件。恢复先进入隔离目录、关闭旧授权，
逐项核验后再考虑切换；校验通过不等于应用恢复验收完成。MySQL/PostgreSQL 备份方式及代理安装见
[部署说明](operations/deployment.md)。浏览器尚未同步的草稿不属于服务器备份范围。
