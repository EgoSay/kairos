# Kairos 1.1.0 功能说明与个人体验清单

适用版本：1.1.0。整理日期：2026-10-11（北京时间）。入口与按钮名称按本次发布源码核对。

这份清单供 Evan 亲自操作，所有勾选项初始均为**待体验**。已完成的工程验收见[发布报告](kairos-1.1.0-release-verification.md)，不代替个人体验结果。

## 先从哪里开始

打开 [Kairos 首页](https://memos.cjwdream.top/)。桌面导航在左侧；窄屏先展开侧边栏。编辑旧记录时，可以点击记录日期进入详情，再选择编辑。

| 本次变化 | 在哪里 | 怎么开始 |
| --- | --- | --- |
| Markdown 即时渲染与格式编辑（R12） | 新建或编辑记录的正文区 | 输入 Markdown，或选中文字使用格式工具栏；上方可切换「Markdown 源码」 |
| 图片粘贴、上传反馈与恢复（R03） | 正文光标位置 | 复制图片后按 Cmd+V；Windows/Linux 为 Ctrl+V |
| 聚焦编辑（R05） | 编辑器上方「聚焦」 | 进入后继续写，使用右上角退出/收起按钮返回 |
| 快捷位置与常用地点（R04） | 编辑器下方「添加位置」 | 搜索公开地点、手动选点、选近期/常用地点，确认后保存记录 |
| 搜索和预览关联记录（R06） | 编辑器下方「关联记录」 | 输入关键词，点击结果预览，再点「关联」 |
| 关键词与组合筛选（R02） | 左侧「查找记录」→「筛选」 | 输入普通关键词，组合日期、标签、分区和媒体条件，再「应用筛选」 |
| 未标签快捷入口（R02） | 左侧标签区「未添加标签」 | 一键筛选，也可在查找窗口勾选同名条件 |
| 嵌套标签树（R09） | 左侧标签区 | 用 `#父级/子级` 建立层级；箭头展开，名称筛选 |
| 置顶及状态规则（R10） | 自己的记录操作菜单；回顾卡片也有直接「置顶」按钮 | 置顶后回首页核对；再次操作取消 |
| 分区保存修复（R01） | 编辑器下方分区选择 | 只改分区也可以保存；正文与分区一起提交 |
| 附件预览与回收规则（R07） | [附件页](https://memos.cjwdream.top/attachments) | 「使用中 / 未关联 / 回收站」切换；点击图片或播放音频 |
| S3 备份管理与状态（R08） | [数据与备份](https://memos.cjwdream.top/journal/backup) →「查看备份与同步状态」 | 管理员查看任务、保护时间、历史、恢复验证和监控 |
| Agent 只读接入（R11） | [设置 → Agent / MCP](https://memos.cjwdream.top/setting#agent) | 创建独立只读凭据，复制客户端配置，检测并连接 Codex |

**建议顺序：先做 1–8 的日常体验，再看 9 的备份状态，最后配置 10 的 MCP。** 离线与新一轮恢复可按需体验，不必和日常路径一次做完。

## 准备三条临时记录

使用新记录和不含隐私的图片，方便区分旧资料。先保持未分区，不启用外发。以下是正文，不需要另外填标题：

```markdown
KR110体验-A 今天散步，想把生活中的小事记下来。
#体验110/生活/散步
```

```markdown
KR110体验-B 今天阅读，想到一个新的角度。
#体验110/阅读
```

```text
KR110体验-C 这是一条暂时不加标签的记录。
```

给 A 粘贴两张容易分辨的图片。C 保持没有 `#标签`，用来验证未标签筛选。验收期间保留这三条记录，结束后统一移到「最近删除」即可。

## 1. 写作与 Markdown（R12）

变化：正文默认即时渲染，格式按钮与源码编辑共用一份内容。常用标题、粗体、斜体、列表、任务列表、引用、链接与代码可直接编辑；较窄的工具栏将部分按钮放在「更多格式」。光标附近可能显示 Markdown 标记，便于编辑语法。

- [ ] **U01｜基础编辑**：新建 A，输入中文；选中一句话用格式按钮加粗，再加一个列表和引用，保存后重新打开。**预期：**格式能显示，文字、段落顺序与中文输入正确。
- [ ] **U02｜源码往返**：编辑 A，点击「Markdown 源码」，查看或修改一处语法，再点「切换可视化编辑」，反复切换后保存。**预期：**正文不丢失、不莫名增加空行，列表与图片仍在原位置。
- [ ] **U03｜撤销与输入法**：用中文输入法写一句话，加粗其中几个字，再撤销、重做。**预期：**候选词确认正常；撤销只撤回对应操作，光标与选区可继续使用。

Mac 可用 Cmd+Enter 保存；普通 Enter 换行。主按钮在新建时显示保存，编辑时可能显示更新；启用分区同步时会明确显示「保存并同步」。

## 2. 复制粘贴图片与上传（R03）

变化：剪贴板里的图片可直接进入正文，不必每次打开文件选择器；上传和失败状态可见，待上传文件随本机草稿保留。

- [ ] **U04｜光标处插图**：在 A 的两段文字之间放置光标，复制一张截图并 Cmd+V；再粘贴另一张，观察上传状态，保存后刷新。**预期：**两张图各出现一次，顺序和位置正确，可打开预览。
- [ ] **U05｜图文与纯文本**：复制一小段带粗体、列表的内容粘贴；然后先点编辑器上方「纯文本粘贴」，再按普通 Cmd+V。**预期：**普通粘贴保留可识别的基础格式；开启纯文本后，这一次只保留文字，后续普通粘贴恢复正常。按钮再点一次可取消待粘贴状态。
- [ ] **U06｜离线恢复，可稍后做**：在已登录并成功打开过的浏览器中，新建以 `KR110体验-离线` 开头的记录；断网后继续写并粘贴测试图片，等待「草稿已保存在此设备」，刷新，再恢复网络并完成保存。**预期：**文字和待上传图片恢复；上传能继续，失败项可以重试；保存后只有一条记录、每张图片只有一份插入。

「草稿已保存在此设备」表示本机持久保存，服务器尚不一定收到。清理浏览器数据会清掉未同步草稿。复制网页图片时，只有剪贴板实际提供的图片文件会上传；远程图片链接不会被悄悄下载。Ego Lite 本轮验证使用「纯文本粘贴」按钮加普通 Cmd+V，带 Shift 的原生快捷键未作为通过依据。

## 3. 聚焦模式（R05）

变化：入口直接显示在编辑器上方，写作状态随模式切换保留。

- [ ] **U07｜切换不丢状态**：编辑 A，选中几个字，点「聚焦」，继续写作后使用右上角退出/收起按钮返回。**预期：**正文、选区/光标、图片、已选位置和关联保留；不需要重新打开记录。
- [ ] **U08｜长文与小窗口**：把编辑器滚到正文中间，进入/退出聚焦，再把浏览器缩窄，添加几个关联。**预期：**回到写作位置，正文仍能编辑；滚动能到达保存按钮。特别短的窗口允许滚动，不要求保存按钮始终固定在视口内。

## 4. 位置与常用地点（R04）

入口：编辑器下方「添加位置」，已有位置时为「修改位置」。选中地点后还要在弹窗确认，并保存整条记录。

- [ ] **U09｜手选位置**：打开弹窗，搜索一个公开的公园或车站，核对城市与地图，选择后确认并保存。**预期：**记录显示你确认的地点；只打开弹窗或浏览默认地图不会自动给记录加位置。
- [ ] **U10｜常用地点**：选好坐标后填一个自定义名称，点「保存为常用地点」；编辑 B 时选择它。之后修改这个常用地点的名称。**预期：**下次可快捷选择；以前保存的记录不被批量改名。
- [ ] **U11｜定位与失败恢复**：点「使用当前位置」。有坐标时核对位置与精度后确认；若失败，直接改用搜索或手动选点。**预期：**错误原因可见，仍可继续记录；手动选好后，迟到的定位响应不覆盖它。

本机上次实测：浏览器权限已允许，但设备返回“位置不可用”，没有坐标。允许权限表示可以请求，不能保证定位服务产出结果；本项允许记录“设备定位未成功，手选正常”，不要将其勾成 GPS 定位成功。搜索地点会把关键词发送到 OSM；私人地点可直接手选并自定义名称。

## 5. 关联记录（R06）

变化：写作中可搜索旧记录、先预览再关联，保存后从两端回看。

- [ ] **U12｜查找并关联**：编辑 B →「关联记录」→ 搜索 `KR110体验-A`；点击结果正文预览，再点右侧「关联」，回到编辑器保存。**预期：**不离开写作流程，关联的是你预览的 A；反复操作不会重复添加同一个目标。
- [ ] **U13｜双向回看**：保存后从 B 打开 A，再检查 A 的关联/「被引用」区域返回 B。**预期：**两个方向都能找到对方，日期与正文可核对；打开预览、返回写作后原草稿和滚动位置保留。

关联查询包括本人归档记录，排除最近删除；自己和已选记录不能重复关联。目标失效时会说明关联未保留，不把整篇正文一起丢掉。

## 6. 搜索、未标签与嵌套标签（R02、R09）

入口：左侧「查找记录」。使用普通文本模式；若上次停在「高级搜索」，先切回文本。展开「筛选」，在「当前范围」与「全部本人记录」之间选择需要的范围。

- [ ] **U14｜关键词**：输入 `KR110体验` 搜索。**预期：**能找回 A、B、C，无需写表达式；搜索 `KR110体验 散步` 时多个词共同匹配。尝试一个不存在的词，应显示无结果，而不是报错。
- [ ] **U15｜组合筛选**：展开「筛选」，选记录创建当天、勾「有图片」，点「应用筛选」；再尝试包含/排除标签、分区。**预期：**A 符合时出现，纯文字 B/C 被排除；已选条件可查看和移除，清空后恢复相应范围的结果。
- [ ] **U16｜未添加标签**：先清空旧条件，再点标签区「未添加标签」；也可在查找窗口将 `KR110体验` 与「未添加标签」组合。**预期：**能找到 C，带子标签的 A/B 不混入；给 C 加标签并保存后，它退出未标签结果。
- [ ] **U17｜父子层级**：在标签区找到「体验110」，点名称后检查 A/B，再点子级「生活」和「阅读」。**预期：**父级包含后代；生活分支能找到 A，阅读分支能找到 B，同一条记录不重复显示。
- [ ] **U18｜折叠与精确匹配**：点标签左侧箭头折叠/展开，刷新；在搜索筛选中取消「包含子标签」，只选 `体验110`。**预期：**折叠状态保留；箭头不触发筛选，名称可筛选。如果正文只写了子标签、没直接写 `#体验110`，仅本级返回零条是正确结果。

若仍看到平铺标签，点标签区右侧「…」→ 勾选「树形显示」。包含多个标签时可选「包含全部所选标签 / 包含任一所选标签」。默认父标签包含后代，但 `体验110者` 不属于 `体验110`。回收站不参与普通搜索；需要归档内容时选择全部本人记录，或使用「包含归档」。日期遵循记录原始时间及 Kairos 时区。

## 7. 置顶与分区保存（R10、R01）

- [ ] **U19｜置顶**：清空筛选，置顶 B 后回首页并刷新，再取消置顶。**预期：**B 在当前列表优先展示、只出现一次，原始日期不变；取消后按正常规则排序。
- [ ] **U20｜置顶服从筛选**：保持 B 置顶，筛选 A 的标签或「有图片」。**预期：**不符合条件的 B 不会强行出现；「已置顶」条件可用于只看置顶记录。
- [ ] **U21｜归档与恢复，可稍后做**：将置顶 B 归档，查看首页与归档，再取消归档。**预期：**归档时不被置顶带回首页；取消归档后仍按置顶状态和当前筛选展示。
- [ ] **U22｜只改分区**：在[分区与同步](https://memos.cjwdream.top/journal/partitions)准备两个未配置外发目标的临时分区；编辑 A，只切换分区，正文不动，保存并重开；再移出分区保存。**预期：**每次选择都持久化，不出现“没改正文所以不能保存”。
- [ ] **U23｜正文和分区同存**：给 A 增加一句话，同时换到另一个临时分区，一次保存后刷新。**预期：**新正文与新分区同时生效，列表和详情一致。

这里的分区是编辑器中的生活记录分区，不是左上角的空间切换。实际外发只按成功保存后的最终授权执行；个人体验用无外发目标的分区即可。真实社媒平台接入本轮仍暂缓。

## 8. 附件、回收站与版本（R07、历史回归）

入口：[附件](https://memos.cjwdream.top/attachments)、记录「…」里的「原文件 / 最近版本 / 移到最近删除」，以及[最近删除](https://memos.cjwdream.top/journal/trash)。

- [ ] **U24｜预览与原件**：在附件页打开 A 的两张图，切换、缩放、关闭，再从记录「原文件」下载一张；有音频可播放试听。**预期：**预览能打开且可退出，下载的是对应原件；不是只有缩略图正常。
- [ ] **U25｜随记录回收**：仅将临时 A 移到最近删除；查看附件「使用中」与「回收站」，再搜索 A。**预期：**A 不在普通搜索中，独属于 A 的附件退出使用中并进入回收站；不要拿仍被其他有效记录引用的原件判断“应被删除”。
- [ ] **U26｜一起恢复**：在最近删除恢复 A，或在附件回收站点「恢复所属记录」。**预期：**正文、图片、预览和来源重新可用；普通列表与计数更新。恢复内容保持私密，旧分享与外发授权不会自动复活。
- [ ] **U27｜旧版本和现有内容**：对临时记录做一次正文修改并保存，打开「最近版本」查看先前内容；再只读打开几条自己的历史记录及原图片。**预期：**版本弹窗不一闪即逝，旧正文可阅读；原有日期、文字与附件仍正确。
- [ ] **U28｜可带走的档案**：在「数据与备份」点击「下载 ZIP 档案」，需要时勾「同时包含最近 30 天的编辑历史」；解压查看 Markdown 和媒体。**预期：**自己的记录、日期、关系和可用原件可读；缺失外链等情况有说明。

「使用中」「未关联」「回收站」是不同状态。回收内容保留 30 天，仍有有效引用或历史版本引用的文件受保护。本次体验无需点永久删除或批量清理，也无需将导出的全量档案重新导入生产。

## 9. 备份与同步状态（R08）

入口：[数据与备份](https://memos.cjwdream.top/journal/backup) →「查看备份与同步状态」，或直接打开[状态页](https://memos.cjwdream.top/journal/backup/status)。整实例配置和状态仅管理员可用；普通用户仍可导出个人 ZIP。

已有目的地继续生效，首次体验无需重填密钥或更换配置。今后修改 S3 时，流程为：填写 endpoint、region、bucket、前缀、凭据、独立保管的恢复密码与备份间隔 →「1. 检测实际读写」→「2. 完整试备份」→「3. 保存并启用」。前两步通过后才能启用；失败不替换原有效配置。

- [ ] **U29｜看懂保护状态**：打开状态页，核对「数据保护时间点」「最近成功完成」「下次自动执行」，展开一条备份历史。**预期：**能看到快照、备份范围、完整性与恢复状态；本机待同步草稿单独列出，没有被算进服务器备份。
- [ ] **U30｜立即备份，可稍后做**：点击一次「立即备份」，等任务完成；可以关闭页面再回来。**预期：**服务器任务继续运行，成功后产生新回执与保护时间；运行中或失败有明确状态，不能只看旧成功记录。
- [ ] **U31｜恢复证据与监控**：展开本次发布快照 `cc0dcb614758…` 的历史，查看隔离恢复、应用可用性及测试版本/提交；同时看「独立监控」和「独立副本」。**预期：**能区分文件校验、应用已验证和未验证；监控投递另有结果。独立副本当前没有可核验回执，显示未知是已知边界，不等于主 S3 备份失败。

如果要亲自重做恢复，可选成功快照的「从此快照隔离恢复并核验」；它创建独立目录，不替换线上数据，会消耗额外时间和空间。等待该任务自己的应用验收结果，不能用另一份快照的成功替代。完整实例备份目前保护 SQLite 及受管附件；MySQL/PostgreSQL 的备份策略另见[部署说明](deployment.md)。

## 10. Agent / MCP（R11）

入口：[设置 → Agent / MCP](https://memos.cjwdream.top/setting#agent)。Kairos 提供只读记录接口；分析由连接它的 Codex 等客户端完成，**不需要为了 MCP 在 Kairos 另外配置 AI 模型服务**。应用内 AI 洞察仍在 [#21](https://github.com/EgoSay/kairos/issues/21) 暂缓。

- [ ] **U32｜创建与检测**：用途写「个人体验 Codex」，有效期选 7 天，点「创建只读凭据」，复制新凭据并点「检测 MCP 连接」。**预期：**检测显示真实只读连接结果；授权列表显示用途、期限。密钥只在创建时返回，不把它贴到聊天或仓库。
- [ ] **U33｜真实客户端读取**：点「复制 Codex 配置」，按[接入说明](agent-access.md)加入实际客户端；在启动客户端的受控环境设置 `KAIROS_MCP_TOKEN`。在连接后的 Codex 使用下方第一段提示。**预期：**能读取当天测试记录并提供可打开的原文链接；网页检测成功与客户端已连接分别确认。
- [ ] **U34｜日期、分页与回顾**：使用下方第二段提示，将日期替换为测试记录的原始日期；如有多页，要求读完。**预期：**按 Kairos 时区和原始日期返回，明确读取范围，原文引用可核对；结果不完整时明确说明，没有记录和请求失败不混淆。
- [ ] **U35｜撤销**：回到「已授权的 Agent」，撤销刚才的测试凭据，再让同一客户端读取。**预期：**下一次请求被拒绝；不能继续用已撤销凭据查询，其他独立凭据不受影响。

第一次读取可直接对已接入 Kairos 的 Codex 说：

```text
使用 Kairos MCP，先确认 Kairos 时区和今天日期。
只查询今天包含“KR110体验”的记录；如果有分页，请继续读取到结束。
列出原始时间、一句摘要和每条原文链接，并说明共读取多少条、是否覆盖完整结果。
不要修改记录；如果没有记录或请求失败，请区分说明。
```

指定日期与比较可说：

```text
使用 Kairos MCP，读取 2026-10-11 当天包含“KR110体验”的所有记录，完成全部分页。
对比其中散步和阅读两条记录：分别列出原文事实、引用，以及你推测的差异。
每个判断注明来源链接，不把推测写成我的事实，也不回写 Kairos。
```

日期需换成你实际创建记录的日期。专用凭据只读本人正常与归档记录，默认排除回收站；不授权图片、音视频原件下载，也不能改记录、设置、分享或备份。清单不要求尝试写入真实资料来证明只读。

## 怎样反馈最省事

直接把编号和结果发回本聊天即可；“功能能用，但入口难找/手感不顺”也值得单独记录。

```text
通过：U01、U02、U04……
不顺手：U07 —— 聚焦入口找到了，但……
失败：U25
  操作：对临时 A 点“移到最近删除”，再打开附件使用中。
  预期：A 的独占图片不再显示。
  实际：……
  环境：Ego Lite / 桌面或窄窗口 / 是否离线。
  时间：北京时间……
未体验：U06、U30……
```

截图仅需包含相关操作区，遮住私人记录和凭据。体验结束后，可取消测试置顶、移走测试记录，撤销测试 MCP 凭据；保留遇到问题的测试记录，便于复现。你的结果收到后再记录个人验收，不预先勾选。
