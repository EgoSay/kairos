# Kairos 1.2.0 日常交互改进

本轮承接 [UX01–UX05 交互评审](../design/kairos-interaction-review-2026-10-11.md)。记录日期为北京时间 2026-10-11。工程检查、部署结果与 Evan 的个人体验分别记录；本报告不会将自动化通过记为个人验收。

## 功能与入口

| 任务 | 新交互 |
| --- | --- |
| 找一条记录 | 点击查找，直接输入关键词；下方出现正文片段，点选打开。“未添加标签”“有图片”和日期可以直接叠加。上下键选择，回车打开选中项或查看全部。 |
| 输入、粘贴、继续写 | 首页默认可视化编辑。Markdown 标题、强调、列表、代码、链接与表格在原位置呈现；进入文字继续编辑也不整行显示语法。网页富文本保留基本格式，并提供临时的“保留纯文本”。 |
| 调整格式 | 选中文字出现短工具条；点“格式”展开完整工具。“更多”保留源码和下次纯文本粘贴，普通写作无需切模式。 |
| 关联旧记录 | 编辑器下方点“关联”，搜索并点选一次即回到写作；可就地预览。输入 `[[` 或粘贴本站记录链接也能进入同一选择流程。关系随记录成功保存后提交。 |
| 添加地点 | 点“位置”后直接选常用/最近地点，或输入名称仅记录“家”等地点名。已选地点标签可直接修改、移除。主动选择地图/定位才请求外部服务。 |
| 聚焦与保存 | 聚焦一直可见，保留同一个编辑实例、草稿、选择和撤销历史；保存及私密/外发状态保持可见。 |

地点名不包含虚构坐标；旧记录的真实 `(0,0)` 仍是合法坐标。未修改正文保留原 Markdown；本轮没有替换编辑核心或新增重型依赖。

## 建议亲手体验

以下四项留给 Evan 体验，不预先勾选。可以在一条临时草稿中完成后三项，再自行决定是否保存。

- [ ] 打开“查找记录”，输入一个记得的词，不按回车观察结果；点“未添加标签”，再清除条件。
- [ ] 直接粘贴网页段落或 Markdown，点击已加粗的文字继续写；撤销一次，观察内容与光标是否符合预期。
- [ ] 正文下方点“关联”，搜索旧记录并选中，检查能否自然回到刚才写作的位置。
- [ ] 点“位置”，选择常用地点，或输入“窗边”只记名称；点地点标签重新修改，再试聚焦与退出。

反馈时记录在哪一步犹豫、误点或需要说明，比单纯判断界面是否好看更有助于下一轮改进。

## 审查修复与兼容边界

- 修复原生粘贴与紧接删除被合并为一次撤销、隐藏格式边界删除、链接/强调换段和表格光标定位问题。
- 修复从日历等当前范围进入完整搜索时遗漏保存视图，以及清空不完整日期后仍保持错误状态。
- 无歧义的单个 HTML 站内链接同样提供关联动作；混合正文或不同链接目标不自动识别为关联。
- 常用地点现在进入逻辑备份；恢复校验包含地点和历史版本。目标已有常用地点时保留现有集合，明确提示备份中未恢复数量；相同内容重复恢复无虚假冲突或版本写入。
- 普通记录导出 ZIP 新写 **2.0**，新版继续读取 **1.x/2.x**。真实旧读取器会拒绝 2.0，防止把名称地点静默当成 `(0,0)`；新 ZIP 的接收端需要升级。历史 1.0 golden 未改写。
- API/store 仅新增兼容字段，没有 SQL schema 迁移。已有真实坐标记录及 CAS 哈希保持原契约；旧客户端不能无版本条件地把名称地点改为默认原点。
