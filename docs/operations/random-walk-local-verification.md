## 实现范围

- Go 后台持久增量任务、Cloudflare Workers AI 嵌入与关联判断、原文和问题双路语义召回及词汇补充，最多十二篇候选、四条关联；每条提示验证双方原文位置。
- SQLite / MySQL / PostgreSQL 同步迁移，原子变更登记、租约、版本及资格检查。编辑、删除、排除、权限或服务变更使旧来源失效，模型迟到响应不能重新发布。
- 默认自动选择起点，原文先呈现、局部图、展开依据、单击继续、返回路径、反馈隐藏及撤销。阅读不调用模型或向量索引；按账户隔离缓存，最多二十个邻域、约五 MiB 序列化文本。
- 复用现有 AI 服务配置，单独明确开启后台处理；账户每日预算持久预留，额度不足跨日恢复，永久配置错误等待更改。不存在自动付费升级或替代供应商。
- 万篇库发现并修复随机起点缺索引导致的约十七秒查询；新增大库回归用例。首屏合并共享模块、设置面板按需加载，公共静态资源启用 gzip，不压缩私人 API 或 SSE。

性能库为 10,008 篇合成记录、20,007 条预置关联。以下是开发机结果，不能替代生产硬件与真实模型回填评估。

| 场景 | 样本与结果 | 判定 |
| --- | --- | --- |
| 本机随机起点 API | 50 次，p50 5.13 ms / p95 5.85 ms，最大 16.42 ms | 有界读取通过本机基准 |
| 本机邻域 API | 50 次，p50 1.25 ms / p95 1.58 ms；返回约 10.9 KB | 有界读取通过本机基准 |
| 冷启动直达 | 390px、RTT 100 ms、10 Mbps、CPU 4 倍限速、缓存关闭；5 次，1.94–2.19 s，p50 2.09 s | **未达到 1.5 s 目标**；原版本约 4.0 s，资源请求由约 123 减至约 42 |
| 已预取连续切换 | 20 次，DOM 更新 p95 7.5 ms，20 次均未新增邻域请求；双 rAF p95 75.5 ms、最大 1016.8 ms | 存在浏览器调度干扰，不能据此认证实体设备全部首帧目标 |

ego lite 空闲 rAF 基线有约一秒节流，最慢切换包含该影响；保留该异常，不删除慢样本。冷启动数据为原文 DOM 可见时刻，不能冒充真实屏幕绘制。未认证缓存未命中 p95 800 ms、物理手机首帧、后台增量 p95 两分钟、真实召回质量与每千条实际费用。
