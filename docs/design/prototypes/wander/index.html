kKairos随机漫步

关于这个原型

三个基础方案与 A+C 组合版使用同一组人工编写的虚构记录与关联，供比较交互手感。原型不访问 Kairos 账户、不调用模型，也不代表真实关联质量或正式应用性能。方案切换、长文开关位于原型外框，正式产品无需选择阅读模式。

设计参考：flomo 随机漫步、Kairos BRAND.md。
