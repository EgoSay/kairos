设计方向原型

配色已定松绿，内容字体已定文楷——字体分层：你写的内容（标题/正文/书写区）用文楷， 界面信息（侧栏/按钮/数字/时间戳）保持黑体，代码保持等宽。 右上角仍可切换到"全黑体"或"宋体标题"作对照。书写区可直接输入感受。

四个方向

A · 墨蓝现状蓝的精修版。最中性、最"工具"，品牌感最弱，但零风险。 打开 → B · 松绿标识松绿直接当主色。保存按钮、链接、热力格全绿，琥珀只留在标识点。字体与细节已按选定方向精修。 当前选定 打开 → C · 青墨 + 琥珀备选：主色向松绿靠拢的墨，琥珀做"时刻"点缀。保留作对照，若松绿过重可回退到此。 打开 → D · 夜读松绿的暗色检验版。同一组语义变量只换取值——证明 token 分层能扛住明暗两态。睡前记录的场景。 打开 →

本轮体验时看什么

  • 字体分层：正文、页标题、书写区是文楷；侧栏导航、按钮、日历数字、时间戳仍是黑体——温度的边界划在"你写的东西"和"界面"之间。在书写区打字感受最明显。
  • 文楷标题无粗体：memo 里的一级标题收敛到正常字重，避免手写体合成粗体发糊。
  • 文字选中：划选一段正文，选中色是松绿淡彩而不是系统蓝。
  • 中西文混排：中文与英文/数字之间的自动空距（如"flomo 上"）。
  • 保存按钮：内高光 + 底边厚度 + 按下 0.5px 下沉。
  • 书写卡聚焦：点击进入书写区，卡片浮现松绿聚焦环。
  • 滚动条：细胶囊半透明，不再用系统粗条。
  • 热力格：保持松绿热力；若想要琥珀热力告诉我。

这一轮不在比较范围内

  • 布局结构：四个方向的骨架完全一致（侧栏 256px / 阅读栏 672px），布局决策另行讨论。
  • 真实数据密度：演示数据偏稀疏，实际长文、大图、密集标签下的观感需第二期验证。
  • 交互动效：静态态和悬停态已收敛；完整动效时长/缓动规范在设计系统文档里定。
